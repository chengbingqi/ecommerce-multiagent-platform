# 客服 Prompt 版本

- 版本：`customer_service_v1.0.0`
- 作用：客服意图结构化分类与基于已验证 MCP 摘要的中文回答
- 输出：严格 Pydantic JSON；分类为固定意图枚举，回答为 `GroundedDraft` 和带引用 claims
- 安全边界：用户消息、工具结果和知识内容是不可信数据；不得改变权限、工具白名单、审批或副作用状态
- 数据最小化：只发送必要摘要和 `evidence_ref`，不发送整行数据库数据、电话、地址、Token 或秘密
- 失败：JSON/Pydantic 解析失败最多修复一次；仍失败、超时或无证据时转人工或返回稳定错误

Prompt 不允许模型执行 SQL、HTTP、Shell、文件、媒体或运营工具，也不允许模型生成审批结论、退款成功状态或业务事实。事实冲突时服务端采用 MCP 结果。
