# 项目路线图

本路线图描述公开版本已经具备的能力、当前边界和后续演进方向，不作为内部阶段验收记录。

## 已实现能力

- React/FastAPI 工程骨架、可重复迁移与模拟业务数据。
- business、knowledge、media 三类 MCP 工具服务及统一权限、证据、审计和幂等约束。
- 客服、运营分析和直播切片三个专业 Agent。
- 有限子任务、有限跳数、可恢复 checkpoint 和部分成功语义的 Orchestrator。
- Session、CSRF、RBAC、对象范围校验、Redis 限流及安全审计。
- MinIO、Celery、ASR、FFmpeg、字幕、质量检查和人工复核组成的受控媒体流水线。
- 固定评测清单、前后端自动化测试和演示资源。

## 当前边界

- 默认使用本地模拟数据；不连接真实店铺、支付或媒体发布平台。
- 知识检索当前采用 PostgreSQL 关键词检索，不宣称已实现向量检索。
- 直播切片属于实验能力，所有结果必须人工审核，不能自动发布。
- 仓库提供本地运行配置；生产凭据、域名、备份目标和公网部署不属于公开演示的默认范围。
- GPU 媒体任务仅在资源明确分配后启用，并保持单任务并发。

## 后续方向

- 增加可复现的跨 Agent 质量、延迟和成本基准。
- 为知识检索增加可替换的向量后端，同时保留证据引用和租户隔离。
- 扩展 Prompt 版本、离线回归和人工评审数据集。
- 改进媒体内容质量评测、失败恢复和资源观测。
- 提供面向全新环境的最小化安装与验收流程。
